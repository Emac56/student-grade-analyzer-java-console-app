# Student Grade Analyzer — Java console app

A small Java console application that analyzes student grades. It reads grades, computes averages, assigns basic letter grades, and prints a simple summary report. This project is intended for practice and learning purposes.

Features
- Compute average grade per student
- Assign letter grades (A/B/C/D/F)
- Print class summary and basic statistics
- Simple console input/output for hands-on practice

Technology
- Java
- Gradle (Gradle Wrapper included)
- Can be opened and run in Android Studio

Run
1. Open the project in Android Studio.
2. Build and run using Gradle or the IDE run button (e.g., `./gradlew run`).

Usage
- Follow the console prompts to enter the number of students and their grades.

Note: This project is for practice purposes only — not production-ready.
